# EvidenceFirst — 근거 기반 사업성과 분석

공개 재무·산업 데이터로 평가점수의 90%를 계산하고, 근거가 확인된 생성형 AI 보조평가를 10%만 반영하는 기업 분석 시스템.

- 원본 제안서: `기업_프로젝트_성공가능성_분석_제안서.docx` (v1.0, 2026-10-06)
- 첫 대상: 사업구조가 비슷한 국내 상장 전자부품 제조기업 (파일럿 5개 → 비교군 20~40개)
- 첫 출력: 사업성과 평가점수(0~100), 위험 경보, 경쟁사 비교, 근거 보고서
- **성공확률은 제공하지 않는다** — 결과 라벨·시간순 검증·보정을 통과한 뒤 별도 단계로 진행

## 핵심 원칙

1. 모든 점수는 원본 공시와 계산식까지 역추적된다.
2. 같은 데이터·규칙 버전이면 구조화 점수가 그대로 재현된다.
3. 자료 부족은 0점이 아니라 결측·부분 평가·보류로 처리한다.
4. AI 비중은 코드에서 10%로 고정한다. LLM은 계산식·가중치·90% 영역의 숫자를 바꾸지 못한다.
5. 점수와 확률은 화면에서도 다른 이름으로 표시한다.

## 점수 구성 (company-v1 초안)

| 영역 | 배점 |
|---|---|
| 재무 안정성·현금창출 | 35 |
| 성장성과 지속성 | 20 |
| 운영 경쟁력 | 20 |
| 시장·외부환경 | 15 |
| AI 정성평가 | 10 |

## 기술 스택

Python · pandas · SQLite · Streamlit. 이후 FastAPI → Docker → AWS로 확장한다.
