# 진행 기록

## 시작 전 준비
- [ ] OpenDART 인증키 신청 (https://opendart.fss.or.kr) — 1주차 첫 작업에 필요
- [ ] 키는 `.env`에만 저장, 저장소에는 `.env.example`만 둔다

## 1주차 — 자료·평가 정의 확정

### 1단계: 문제 정의 (함께 정리)
- 이 시스템이 답할 질문은 무엇인가? (제안서 2.1의 5개 질문)
- 첫 버전에서 "결과"는 점수인가 확률인가, 왜?

### 2단계: 사용자 설계 질문
1. 파일럿 5개 기업을 어떤 기준으로 고를까? (주요 제품·제조 여부·규모·결산월)
2. 원본 데이터를 어떤 형태로 저장할까? (DART 응답 JSON 그대로 vs 정제 CSV vs 둘 다)
3. 한 행(row)은 무엇을 나타내야 할까? (기업×연도×계정? 기업×연도?)
4. 표준 계정 ID는 어떻게 정할까? (DART `account_id` 재사용 vs 자체 ID)
5. 연결·별도가 섞이면 어떻게 할까?

### 첫 세션 목표
기업 한 곳의 4개 사업연도 매출·영업이익·영업현금흐름·총자산을
통화·단위·연결 기준·접수일·공시 ID와 함께 CSV로 정리하고,
매출 CAGR과 영업이익률을 손계산 → Python 함수로 재현한다.
확인하지 못한 계정은 추정하지 말고 이슈 목록에 남긴다.
