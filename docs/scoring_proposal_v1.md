# 점수 규칙 제안 v1 (scoring_v1, 상태: **제안 — 미확정**)

> **v2로 대체됨 (2026-10-07):** `docs/scoring_rules_v2.md`. 이 문서는 v1 기록으로 보존한다. 변동성 감점 조건에 반례가 있었고, 일부 근거 문구(물가 기준 실질성장, "자본잠식" 등)를 v2에서 고쳤다.

README 6절의 지표·방향·배점과 7.1의 변환 방식을 따른다. **고정 구간(B) 경계값은 이 프로젝트의 평가 기준이 되는 값이라 확정 전까지 점수는 변환·기여도 계산의 검증용**이다. 코드에 넣었다고 검증된 기준이 되는 것이 아니다.

경계값은 파일럿 5개사 분포에 맞추지 않았다 (5개로 맞추면 과적합). 아래 근거는 대부분 **관행적 기준이나 해석하기 쉬운 기준점**이며, 업종 검증이 필요하다는 점을 같이 적는다.

## 변환 방식 (README 7.1)
- **A. 비교군 백분위** — 중간순위. 평가기업 제외. **n < 20이면 검증용**(점수에 넣지 않음). 지금 파일럿 비교군은 n = 3이라 A 방식 지표는 모두 검증용이다
- **B. 고정 구간 선형 보간** — 경계점 사이는 직선으로 잇고, 양 끝 밖은 끝점 점수로 고정
- **C. 조건부 점수** — 분모가 실제로 0인 정상 사례 등. **이번 버전은 구현하지 않는다** (해당 사례는 점수 보류)

## 결측·해당 없음 집계 (README 7.3, 자동 재분배 없음)
기업마다 구조화 배점 90을 다음으로 나눠 보인다.
- **확인된 기여도 K**: 정상 계산 + 점수 반영 가능 지표의 `배점 × 점수 / 100` 합
- **미확인 배점**: 입력 보류(참고 계산·계산 안 함), 비교군 조건 미충족(검증용), 미구현(시장 15)
- **해당 없음 배점**: 비교군 제외 등 — 범위 계산에서도 따로 표시하고 종합점수는 산출하지 않는다
- 범위: 하한 = K, 상한 = K + 미확인 배점 (AI 10은 별도 미제공). 가중 커버리지 = 점수 반영 배점 / 90
- **종합점수는 보류** — 시장 지표 미구현, 비교군 n < 20, 규칙 미확정

## 확정하려면
1. 각 B 경계점의 값과 근거를 검토 (특히 OCF/자산, CAGR, 변동성은 근거가 약하다)
2. 확정하면 `configs/scoring_v1.yaml`의 `status`를 `confirmed`로 바꾸고 확정일·검토자를 남긴다. 값을 바꾸면 버전을 올린다 (v1 → v2)
