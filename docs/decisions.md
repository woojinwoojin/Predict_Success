# 설계 결정 기록

결정마다 무엇을, 왜 정했는지, 무엇을 버렸는지 남긴다. 바꿀 때는 지우지 않고 새 항목으로 대체 관계를 적는다.

## D1. 파일럿은 한 업종, 구조는 범용 (2026-10-07)

**결정:** 파일럿은 화장품 업종으로 좁게 시작하되, 업종에 따라 달라지는 것은 코드가 아니라 설정·데이터에 둔다.
범용성의 기준은 "지원 업종 수"가 아니라 "업종을 바꿀 때 코드를 고치지 않아도 되는가"다.

| 업종마다 다른 것 | 두는 곳 |
|---|---|
| 지표 적용 여부 (예: 재고회전율) | 규칙파일 `metrics_v1.yaml`의 업종별 적용 조건 |
| 시장 통계 위치 (질문 ①) | 업종 코드 → KOSIS 통계표 매핑 (데이터) |
| 비교군 | 기업 목록 + 선정·제외 사유 (데이터, 버전 관리) |
| 계정 이름 | DART 표준 `account_id` 기준 |
| 업종 판단 | 기업개황의 표준산업분류(KSIC) 코드 |

**이유:** README 5절은 V1에서 전 산업 *동시* 지원만 제외한다. 처음부터 화장품을 코드에 박으면 확장 때 다시 짜야 한다.
**버린 안:** 여러 업종을 섞은 파일럿 — 오류가 데이터·코드·업종 차이 중 어디서 왔는지 가리기 어렵다.

## D2. 파일럿 5개 기업 (2026-10-07 확정)

**파일럿 = 계산 엔진과 자료 처리 규칙을 시험하는 표본.** 비교군(순위를 매길 수 있을 만큼 비교 가능한 집합)과 구분한다.
"정상 4 + 까다로운 1"로 나누지 않고, 기업마다 시험할 설계 문제를 지정한다.

| 기업 (고유번호) | 파일럿에서 맡을 역할 | 실제 비교군 포함 |
|---|---|---|
| 코스맥스 (01009789) | 기본 계산 · 해외 종속회사를 포함한 연결자료 처리 | 후보 (화장품 ODM, 매출 90% 이상 ODM) |
| 코스메카코리아 (00763473) | 기본 계산 · 정정공시 이력 처리 (2025 보고서 기재정정·첨부정정) | 후보 (화장품 ODM/OEM) |
| 씨앤씨인터내셔널 (01226410) | 기본 계산과 원문 대조 (연결≈별도, 100% ODM) | 후보 (색조 ODM) |
| 한국화장품제조 (00160621) | 별도재무만 있는 사례 · 정정자료 처리 (2024·2025 보고서를 2026-08-13 정정) | 후보 (OEM·ODM, 화장품 매출 98.3%) |
| 한국콜마 (00939331) | 여러 사업이 섞인 연결자료의 비교 가능성 판단 | **보류** — 연결에 전문의약품(HK이노엔)·H&B·패키징(연우) 포함. 연결 그대로는 화장품 ODM과 비교 불가, 처리 규칙을 정한 뒤 결정 |

**추가 검증 대상:** 씨티케이 (01144028) — 무공장(Fabless) 풀턴키 플랫폼이고 2025-03 미국 OTC 제조시설을 인수. 같은 제조 구조의 비교기업으로 바로 확정하지 않고 사업구조를 따로 확인한다.

**공통 조건:** 화장품 제조(KSIC 20423), 코스피·코스닥 상장, 12월 결산, 2022~2025 사업보고서 4년치 존재 (6개사 모두 확인).

**후보 탐색 방법:** 회사 이름이 아니라 업종 코드 → 상장사 목록 (상장사 3,998개 기업개황 스캔, 20423 상장사 24개) → 사업구조로 2차 분류.
KSIC가 같아도 ODM과 자체 브랜드는 사업구조가 달라서, D1의 "업종 판단 = KSIC"는 **KSIC 1차 + 사업구조 2차**로 보완한다.

**확인한 근거 (2026-10-07):**
- 사업 내용: 각 사 2025 사업보고서 "II. 사업의 내용 — 1. 사업의 개요" 원문
- 수치: 5개사 2025 매출·영업이익·당기순이익(연결, 한국화장품제조는 별도)을 사업보고서 요약재무정보와 대조 → 15개 값 모두 일치. 2022~2024는 아직 대조하지 않음
- 원본: `data/raw/dart/` (API 응답 JSON, 사업보고서 원문 zip — git 제외)

## D3. 자료 처리 원칙 (파일럿 검토에서 나온 것, 2026-10-07)

1. **적자·음수 영업현금흐름은 관측값이다.** 자료 부족이 아니므로 점수와 위험 신호에 그대로 반영하고, 그것만으로 부분 평가·보류하지 않는다. 부분 평가·보류는 필요한 자료가 *없을* 때만.
2. **분모 예외는 분모에서만 생긴다.** 이자보상배율의 영업이익, OCF/자산의 OCF는 분자라 음수여도 계산된다. 분모(이자비용·자산·매출·재고 등)가 0·음수인 경우는 파일럿 실제 데이터에 기대지 않고 **별도 테스트 데이터**로 준비한다.
3. **과거 시점 분석에는 당시 원본과 정정 이력이 필요하다.** 재무 API(`fnlttSinglAcntAll`)는 정정 후 최신 값을 준다. 접수번호·접수일 저장만으로는 "기준일에 알 수 있던 숫자"를 복원할 수 없으므로, 최초 보고서 원본과 정정 이력(정정 전·후, 접수일)을 함께 보관해야 한다. 수집 방법은 1-2 원본 저장 형태에서 정한다.
4. **보고서마다 금액 단위가 다르다.** 같은 업종 2025 보고서에서도 원·천원·백만원이 섞여 있다 (API는 원 단위). 값마다 단위를 기록하고 정제 단계에서 통일한다.
